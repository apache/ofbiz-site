Open Source PIM and Product Catalog Management

Apache OFBiz keeps all your product information in one place. This is called PIM, short for product information management. OFBiz holds products, variants, prices, images and stores, and shares them with orders and stock. It is free and open source under the Apache License 2.0.

Who it is for

  • Teams that manage thousands of products, with sizes, colors and other options.
  • Businesses that sell through several stores, each with its own catalog and rules.
  • Merchandisers who set prices, price rules and promotions.

What OFBiz does for your product catalog

Products, with all their details

Each product has a name, a type, descriptions, weight and size. You can add codes such as SKU, UPC, EAN and ISBN. Physical goods, services, digital downloads and subscriptions are all products. User manual: Catalog, Products

Variants: sizes, colors and other options

A virtual product is the item a customer chooses, such as a T-shirt. Its variants are the real items you stock, such as "red, large". OFBiz creates the variants for you from the features you pick. Guide: Avoiding Redundant BOMs with Virtual and Variant Product Design in Apache OFBiz

Features and attributes

Features describe a product, such as color, size or material. Group them into feature categories, and mark features that cannot go together. Add free attributes for any other detail. User manual: Catalog, Features

Categories and catalogs

Put products in categories, and categories inside other categories. A catalog is a set of categories that one store shows. One product can sit in many categories and catalogs. User manual: Catalog, Categories

Product stores

A product store holds the rules for one place you sell. Each store has its own catalogs, warehouses, tax, shipping, payment settings and customer emails. User manual: Catalog, Stores

Prices and price rules

Give each product a default price and a list price, in each currency. Price rules then change the price for some products, customers or quantities. Guide: Set Product Prices and Price Rules in Apache OFBiz

Promotions and coupon codes

Set up an amount off, free shipping or a free gift. A promotion can need a coupon code, and can have limits per customer. Guide: Set Up Promotions and Coupon Codes in Apache OFBiz

Product text and images

Write the name and the short and long descriptions. Add a page title and meta tags for search engines. Upload product images. OFBiz makes the small, medium and large sizes for you. Image Management lets staff approve or reject new images. User manual: Catalog, Image Management

Cross-sell, upsell and other links

Link products to each other as cross-sell, upsell, accessory or replacement. The online store shows these links to customers. User manual: Catalog, Products

Configurable products

Let customers build their own product from options. An example is a computer with a chosen disk and memory. Each option can change the price. User manual: Catalog, Configurations

Gift cards

Sell gift cards and let customers pay with them. Each store sets its own gift card rules, such as whether a PIN is needed. User manual: Catalog, Stores

Keyword search

Staff find products by keyword, category or feature. OFBiz builds the keywords from the product text. A thesaurus adds other words that mean the same thing. User manual: Catalog, Thesaurus

How it connects with the rest of OFBiz

Orders use the same products, prices and promotions. The warehouse stocks the same variants. See Order Management, Inventory Management and eCommerce.

Try it

  • Open the public demo and go to the Catalog application.
  • Download Apache OFBiz and run it on your own computer.
  • Read the price and promotion guides on the wiki: Apache OFBiz for Order Management.

Questions and answers

Is Apache OFBiz free?

Yes. It is open source under the Apache License 2.0. You can use it, change it and run it at no cost.

Can I run several stores from one catalog?

Yes. Each store picks the catalogs it shows, and sets its own prices and promotions.

Can I load my products from a spreadsheet?

Not from the Catalog screens. Products are loaded as XML data files in the Web Tools application. Many teams ask a developer to write an import for their file.

Does OFBiz have a point of sale for shops?

Not today. The point of sale add-on is no longer part of OFBiz.

Do I need technical skills to set it up?

Yes. OFBiz runs on Java, and setup needs some technical work. The service providers list names people who can help.
