The Apache OFBiz community is pleased to announce the new release "Apache OFBiz 12.04.06". <br><br>Apache OFBiz™ is an open source product for the automation of enterprise processes that includes framework components and business applications. <br><br> [http://ofbiz.apache.org/](http://ofbiz.apache.org/) <br><br> "Apache OFBiz 12.04.06" is a bug fix release for the 12.04 series; all users of Apache OFBiz 12.04.\* series are encouraged to upgrade to this latest release because the new release contains several improvements and bug fixes, including fixes for the following vulnerabilities: <br><br> CVE-2015-3268 - Information disclosure vulnerability<br> CVE-2016-2170 - Java deserialization vulnerability <br><br> Release notes are available here: [Release Notes - 12.04.06](/release-notes/release-notes-12.04.06/) <br><br> Note: this is the last release of the 12.04 series so please consider upgrading to the 13.07 series. <br><br> The release file can be downloaded following the instructions in the OFBiz download page: <br><br> [https://ofbiz.apache.org/downloads/](/downloads/) <br> [https://ofbiz.apache.org/security/#list-of-known-vulnerabilities](/security/#list-of-known-vulnerabilities) <br><br> The OFBiz Team.
